# 🚀 GUÍA RÁPIDA - Versión Python

## ⚡ Instalación en 3 Pasos

### Windows:
1. **Doble clic en:** `instalar.bat`
2. **Doble clic en:** `iniciar.bat`
3. **Abrir navegador:** http://localhost:5000

### Mac / Linux:
1. **Terminal:** `./instalar.sh`
2. **Terminal:** `python3 app.py`
3. **Abrir navegador:** http://localhost:5000

---

## ✅ Requisitos

- ✅ Python 3.8 o superior
- ✅ pip (viene con Python)

**¿No tienes Python?**
Descarga desde: https://www.python.org/downloads/

**IMPORTANTE:** En Windows, marca "Add Python to PATH" durante la instalación

---

## 📝 Uso Rápido

1. Completar formulario
2. Click "Generar Documentos"
3. Descargar archivos Word

---

## 🐛 Problemas Comunes

### "Python no se reconoce"
👉 Reinstala Python y marca "Add to PATH"

### "No module named flask"
👉 Ejecuta: `pip install -r requirements.txt`

### Puerto 5000 ocupado
👉 Windows: Administrador de tareas → Cerrar Python
👉 Mac/Linux: `killall python`

## 🆚 Diferencias vs Node.js

| Aspecto | Python | Node.js |
|---------|--------|---------|
| Puerto | 5000 | 3000 |
| Inicio | `python app.py` | `npm start` |
| Instalar | `pip install` | `npm install` |

**Ambas versiones generan los mismos documentos.**
