## ATAJO DE TECLADO PARA AUTOCOMPLETAR

Para facilitar las pruebas, puede activar el autocompletado:

1. Abra el archivo `public/app.js`
2. Descomente la sección de "autocompletarPrueba" (líneas finales del archivo)
3. Guarde el archivo
4. Reinicie el servidor
5. En el formulario, presione: **Ctrl + Shift + T**

Esto llenará automáticamente todos los campos con los datos de ejemplo.
